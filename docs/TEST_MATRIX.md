# TEST_MATRIX — полевые испытания P0 (iPhone ↔ Android)

Статус всех строк сейчас: **НЕ ПРОВЕРЕНО на физических устройствах.** Заполняется по ходу испытаний. Результаты автотестов и симуляций сюда не переносятся.

## Как проводить

1. Перед сценарием на **обоих** телефонах: Моё → «Метка сценария» → например `3. свёрнуто 30 мин` → «Сохранить». Метка попадает в каждую точку и событие журнала — сводка группирует по ней.
2. Фиксируйте старт/конец по часам и что делали (шли/ехали/лежал на столе).
3. После сценария: `node scripts/summarize.ts` (или экспорт с телефонов) → заполнить строку.
4. Выборка < 20 точек/запросов → помечать вывод «предварительно». Никаких «гарантированных» процентов.

## Расход батареи — методика

- **Контроль:** тот же телефон, приложение в режиме OFF (или удалено), тот же сценарий и длительность, яркость и сеть те же. Заряд старт 80–90 %, без зарядки.
- **Испытание:** ECO и ACTIVE_TRIP по отдельности, ≥ 60 мин каждый.
- **Источник цифр:** уровень заряда в каждой точке (`battery_level`) + системная статистика батареи (iOS: Настройки → Аккумулятор; Android: Настройки → Батарея → по приложениям) — скриншот в конце.
- **Расчёт:** (заряд_старт − заряд_конец) / часы; доля приложения = испытание − контроль. При разнице < 2 %/ч — «не различимо на такой выборке».
